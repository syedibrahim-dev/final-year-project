CloudVault Security — Product Fact Sheet
=========================================

Company: CloudVault Security Ltd.
Product: CloudVault Certificate Manager
Website: www.cloudvault.example.com

PRODUCT OVERVIEW
CloudVault Certificate Manager is an automated certificate lifecycle management platform
for mid-size and enterprise organisations. It discovers, monitors, and auto-renews
SSL/TLS certificates across hybrid cloud environments.

KEY FEATURES
- Automated certificate discovery across AWS, Azure, GCP, and on-premise infrastructure
- Auto-renewal for Let's Encrypt, DigiCert, Sectigo, and custom CA certificates
- Real-time dashboard with expiry alerts (30-day, 14-day, 7-day, 1-day warnings)
- REST API and native integrations with Kubernetes, Terraform, Ansible, and ServiceNow
- Role-based access control with SSO (SAML 2.0 / OIDC)
- Compliance reporting for SOC 2 Type II, ISO 27001, and PCI DSS
- Certificate pinning detection and vulnerability scanning

PRICING

- Professional Plan: $79/month — up to 500 certificates, 5 users, priority support, API access

SECURITY & COMPLIANCE
- SOC 2 Type II certified (annual audit by Deloitte)
- Data encrypted at rest (AES-256) and in transit (TLS 1.3)
- Multi-tenant architecture with isolated customer environments
- Annual penetration testing by independent third party
- GDPR and CCPA compliant data handling

LIMITATIONS (known constraints)
- Does not support legacy certificates (SHA-1 or earlier)
- On-premise agent required for air-gapped environments (no agentless option)
- Maximum 10,000 certificates per single instance (clustered deployment for larger estates)
- Mobile app available for iOS only (Android planned for Q3 2026)

COMPETITIVE POSITIONING
- Primary competitors: Venafi, DigiCert CertCentral, Sectigo Certificate Manager
- CloudVault differentiator: Fastest deployment (3 weeks vs industry avg 8-12 weeks)
- CloudVault differentiator: Only vendor offering real-time vulnerability scanning bundled
- Weakness vs Venafi: Venafi has deeper legacy PKI support and larger enterprise footprint
- Weakness vs DigiCert: DigiCert has native CA issuance; CloudVault is CA-agnostic
