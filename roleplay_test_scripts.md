# Roleplay Test Scripts - Budget Hunter Persona

## Scenario Context
**Customer**: Budget Hunter  
**Starting Budget Range**: $5,000 - $10,000  
**Current Situation**: Using multiple disconnected tools

---

## ✅ GOOD SALESPERSON - High-Quality Conversation

### Message 1: Discovery & Empathy
```
That makes total sense. Using multiple tools can definitely get messy - I've heard that from a lot of clients. What are the biggest pain points you're experiencing with your current setup? Is it mostly about data being scattered, or are there other frustrations?
```

### Message 2: Value-First Approach
```
I completely understand. Managing multiple systems not only costs time but can lead to missed opportunities when information isn't centralized. Our platform actually helps consolidate everything into one dashboard. Before I dive into features, what would success look like for you in the next 6 months if you had the perfect solution?
```

### Message 3: Budget Respect & Solutions
```
Great, that's really helpful to know. I want to be upfront with you - we have solutions that fit within your $5K-$10K range, and they're designed specifically to give you that single source of truth. We also offer flexible payment plans that can make it easier for teams to get started without a huge upfront cost. Would you be open to seeing a quick demo tailored to your specific needs?
```

### Message 4: Building Trust & Next Steps
```
Perfect! I'll set that up. Just to make sure I'm showing you exactly what matters, can you tell me which 2-3 features would be absolute must-haves for you? That way I can make the demo as relevant as possible to your situation.
```

### Message 5: Professional Close
```
Excellent. I'll get that demo scheduled and send you a calendar invite. In the meantime, I'll also send over a quick one-pager with pricing options in your range. Does Thursday or Friday work better for you for a 30-minute demo?
```

---

## ❌ BAD SALESPERSON - Poor-Quality Conversation

### Message 1: Pushy & Dismissive
```
Okay cool. So you're using some random tools and you've got a small budget. Let me tell you about our premium enterprise package - it's $50,000 annually and has everything you could ever need.
```

### Message 2: Ignoring Customer Needs
```
Yeah, but honestly those budget constraints are going to limit what we can do for you. Most of our clients spend way more than that. Have you thought about increasing your budget? Because $10K really won't get you much.
```

### Message 3: Feature Dumping
```
Anyways, let me tell you about all our features. We have AI-powered analytics, machine learning predictive models, blockchain integration, cloud-based infrastructure, API connectivity, mobile apps, desktop apps, web portals, custom dashboards, reporting tools, automation workflows, and about 50 other features I could list.
```

### Message 4: Pressure Tactics
```
Look, I've got a few other calls lined up and I'm trying to hit my quota this month. If you sign today, I might be able to get you a discount. But you need to decide now because this offer expires in 2 hours.
```

### Message 5: Unprofessional Close
```
So are you in or out? I don't have time to chase people around. Let me know by end of day or I'm moving on to the next prospect.
```

---

## 🎯 What the Evaluation Should Catch

### Good Conversation Should Score High On:
- **Rapport Building**: Empathy, active listening, friendly tone
- **Needs Discovery**: Asking about pain points, goals, success criteria
- **Product Presentation**: Addressing budget constraints, offering solutions within range
- **Objection Handling**: Respecting budget concerns, offering flexible options
- **Closing**: Professional next steps, scheduling demo, low pressure

### Bad Conversation Should Score Low On:
- **Rapport Building**: Dismissive, focused on quota not customer
- **Needs Discovery**: Didn't ask meaningful questions about needs
- **Product Presentation**: Pitched expensive solution outside budget, feature dumping
- **Objection Handling**: Ignored budget objection, pressured to increase budget
- **Closing**: High pressure, ultimatums, unprofessional
